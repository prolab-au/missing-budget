# The Missing Budget

A CTF challenge made for Ankara University by PROLAB, the Ankara University student community.

The only signed copy of the computer labs' budget has vanished from Prof. Y.A.'s office. You are the Digital Forensics Unit. Find the thief.

Open this repository's GitHub Pages site to begin.

# Kayıp Bütçe

PROLAB, Ankara Üniversitesi Öğrenci Topluluğu tarafından Ankara Üniversitesi için hazırlanmış bir CTF yarışma sorusudur.
